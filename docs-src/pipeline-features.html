Ports, groups and source views

Endpoint labels use brackets: a[err] -> b[3]. Quote a port containing punctuation: a["2>"]. Brackets label either end of the edge. The standalone parser is exported from js/parse.js; words carry zero-based UTF-16 start/end offsets, and parsed elements carry raw text and attribute spans.

each for x in api web {
  build square echo "$x"
  build[err] -> log double
}

A final unquoted { opens a group; a line containing only } closes it. Groups nest. Nodes belong to the group where first mentioned. Edges may connect to a group box. Previously a bare trailing brace was text: quote it to preserve that meaning.

New shapes: note, cylinder, parallelogram, stadium, subroutine and oval. New edge style: double. These words are reserved in their corresponding optional attribute slots; quote them when intended as text.

Unsaved positions use a deterministic left-to-right layered layout; saved fractional coordinates are preserved. Group boxes grow around their members.

Labels retain full text on hover and keyboard focus. In the drawer, “Show text as written” displays raw quotes in a monospace view. This setting travels with the document. Gripeline comments are highlighted in a preview beneath the source editor.

Append &mark=a,b,L5 to an h1 fragment to highlight nodes and source lines without editing source. Marks are transient link metadata. Gripeline treats double as stderr routing, note/cylinder as files, parallelogram as a stream and subroutine as a command calling a shell function. The hex file alias remains supported.
