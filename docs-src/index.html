modl

modl (Manual Override Diagram Language) is a small, line-oriented text language for drawing node-and-arrow diagrams. Each line declares a node or an arrow. The editor redraws the diagram as you type and keeps the whole diagram, source and layout, in its URL.

hello -> world

Every listing in these docs has an Open in editor link like the one above. The link carries the example's source in its URL, so it opens the editor with that diagram loaded. Change it however you like: nothing is saved anywhere unless you press Save to HashBin.

A quick tour

A node line starts with an id, followed by optional attributes and a label:

api square blue API server db diamond purple Database

An edge line connects ids with ->. Ids that haven't been declared yet become nodes automatically:

browser -> api -> db

Edges take attributes too, and # starts a comment:

# A three-tier web app browser circle teal /developer.mozilla.org Browser api square blue API server db diamond purple Database browser -> api bold blue HTTPS # thick blue arrow with a label api -> db dashed SQL

A line with nothing but a color name sets the background:

white sun big circle yellow Sun earth circle blue Earth sun -> earth dotted orange light

Attributes are optional, but the ones you use must appear in this order. A word that is out of order becomes part of the label instead (see Attributes).

Reading the listings

Using the editor

  • Type in the source pane; the diagram updates after a short pause and the URL updates with it.
  • Drag a node to move it, drag the background to pan, and use +/− to zoom.
  • Hover over a node or edge to see its id, full text, and link. Click to open its link.
  • Source, Diagram, Help and Split switch between views.
  • Copy URL copies a link to exactly what you see. Commit snapshot adds a browser history entry so Back and Forward step between versions.
  • QR code shows a QR code of that link, so an audience can open the diagram on their phones. Long URLs make dense codes; save to HashBin first for a short link that scans easily.
  • Save to HashBin stores the diagram and replaces the long URL with a short one (see Sharing).
