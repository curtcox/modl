Links & image nodes

Any node or edge can carry one URL. Clicking it opens the link in a new tab. If a node's URL points to an image, the node is drawn as that image.

URL syntax

The URL is the fourth attribute slot, after size, style and color. A word is taken as a URL when it starts with one of these prefixes:

You writeLink goes to
/example.com/docshttps://example.com/docstry it
https://example.comunchangedtry it
http://example.comunchangedtry it
www.example.comhttps://www.example.comtry it
mailto:someone@example.comunchanged: opens your mail programtry it

The leading-slash form is the shortest way to write an HTTPS link. It means "https:// plus the rest", not a path on the current site, so relative links aren't possible. A URL is a single word: it ends at the first space, so encode spaces as %20. Query strings and #fragments work, because a # only starts a comment after whitespace.

Links on edges

Edges take a URL in the same position. Click anywhere along the line to follow it:

Clicking, hovering, dragging

  • Click a node or edge to open its URL in a new tab. Nodes and edges without a URL do nothing.
  • Hover to see the node id (or edge endpoints), full text and link in a tooltip.
  • Dragging a linked node moves it without opening the link.

Image nodes

A node whose URL is an image is drawn as the image itself instead of a shape. The editor treats a URL as an image when:

  • its path ends in an image extension (.svg, .png, .apng, .jpg, .jpeg, .gif, .webp, .avif, .bmp, .ico, any letter case), or
  • it has no such extension, but the browser can load it as an image anyway. The editor tries every http(s) node URL in the background, and the node switches to the picture once it loads.

If an image fails to load, the node falls back to its normal shape. Edges never become images, and clicking an image node still opens its URL.

Image size

Without a size, an image is drawn at its natural pixel size. With a size, it is scaled to fit inside that size's node box (110 × 64 for normal; see sizes), keeping its proportions.

Frames and color

An image node has no outline unless you give a shape explicitly, since the default circle isn't drawn. A given shape becomes a frame around the image, filled and outlined in the node's color. Shape none means no frame.

Labels

An image node's text is drawn below the image. An image node without text has no label at all; its id isn't shown. Hover to see the id.

a /curtcox.github.io/modl/docs/img/database.svg Orders DB b /curtcox.github.io/modl/docs/img/database.svg a -> b dashed replica

Because the editor tries to load every node URL as an image, your browser requests each linked page in the background when a diagram opens. This is how images without an extension are detected.

The icons used in these examples live with the documentation at https://curtcox.github.io/modl/docs/img/: user.svg, server.svg, database.svg, cloud.svg and phone.svg. Any publicly reachable image works the same way.
