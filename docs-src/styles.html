Sizes, shapes, lines & colors

modl has 28 reserved words: six sizes, six node shapes, four line styles and twelve colors. They are recognized only in lowercase, and only in their attribute slot.

Sizes

A size scales a node by a fixed factor of the normal node box, 110 × 64 pixels. For edges, size scales only the label. Labels never go below 10px.

Colors

The same twelve colors work for nodes, edges and the background. On a node, the color tints a translucent fill and draws the outline. On an edge, it colors the line and arrowhead. As a background, it is used solid.

The palette nodes need a shape (or any attribute) because a line holding only a color name sets the background.

Label color and backgrounds

A node's label color is chosen from the node's color alone. white, yellow and green nodes get dark labels, and the other nine colors get light labels. The background isn't taken into account, and node fills are mostly transparent, so:

  • On the default dark backdrop, or a black or other dark background, labels on white, yellow and green nodes are hard to read. Use the other colors for nodes with labels.
  • On a white or other light background, it's the reverse: white, yellow and green nodes read best.
  • Edge labels are always light text with a dark outline, so they read on any background.
  • none nodes draw their label in the node's color, so pick a color that contrasts with the background.
